# Plan 05-01: Mock PSP Crate Setup, CLI Command, and Server Infrastructure

## Goal
Structure `minidodo-psp` following workspace standards (`src/lib.rs`, `src/serve.rs`, `src/http/server.rs`, `src/http/routes/`, `minidodo-core/src/config/components/psp.rs`), and wire the `psp` command into `minidodo-cli`.

## Proposed Changes

### 1. `minidodo-psp` Structure
- `Cargo.toml`: Add `minidodo-psp` with workspace dependencies.
- `src/lib.rs`: exports `pub mod http; pub mod serve; pub use serve::serve;`.
- `src/serve.rs`: `pub async fn serve(host: String, port: u16) -> Result<()>`.
- `src/http/server.rs`: `build_http_server` with tracing, CORS, and trailing-slash normalization.
- `src/http/state.rs`: `PspChargeStatus` and `PspChargeResponse` models.
- `minidodo-core/src/config/components/psp.rs`: `MockPspConfig` (`MINIDODO_PSP_HOST`, `MINIDODO_PSP_PORT`).

### 2. `minidodo-cli`
- Add `minidodo-psp` dependency.
- Wire `psp` subcommand loading `load_psp_config()` and calling `minidodo_psp::serve`.

## Verification
- `cargo check --workspace`.
- `cargo run -p minidodo-cli -- psp --help`.
