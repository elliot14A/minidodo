# Plan 05-02: Mock PSP 3-Tier Routes and Simulation Matrix

## Goal
Implement 3-tier routes in `minidodo-psp/src/http/routes/v1/`:
- `GET /v1/health`: Healthcheck endpoint.
- `POST /v1/charges`: Deterministic token simulation matrix per assignment specification.
  - `tok_success` / default: `200 OK` with `{"status": "succeeded", "psp_ref": "<uuid>"}`.
  - `tok_card_declined`: `400 Bad Request` with `{"status": "failed", "code": "card_declined"}`.
  - `tok_insufficient_funds`: `400 Bad Request` with `{"status": "failed", "code": "insufficient_funds"}`.
  - `tok_timeout`: Simulates slow success (`sleep(30s)` -> `200 OK` with `{"status": "succeeded", "psp_ref": "<uuid>"}`).
  - `tok_network_error`: `500 Internal Server Error` with `{"status": "failed", "code": "network_error"}`.
