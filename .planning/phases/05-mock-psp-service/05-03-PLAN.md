# Plan 05-03: Docker Compose Service and Multi-Token Verification

## Goal
Add `psp` service to `docker-compose.yaml` (port 8080:3000), start the service, and verify all token simulation scenarios via `curl`.

## Proposed Changes

### 1. `docker-compose.yaml`
- Add `psp` service:
  - `command: ["psp"]`
  - `ports: ["8080:3000"]`
  - `environment: MINIDODO_PSP_HOST=0.0.0.0, MINIDODO_PSP_PORT=3000`

## Verification
- `docker compose up -d psp`
- Live curl tests for `tok_success`, `tok_card_declined`, `tok_insufficient_funds`, `tok_network_error`, and `tok_timeout`.
