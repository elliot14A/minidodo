# Plan 01-03: Postgres Connection Pool & Lowercase SQL Subsystem Error

## Goal
Implement PostgreSQL connection pool setup, transaction helpers, migration runner, and dedicated `postgres::Error` enum with `impl From<postgres::Error> for MinidodoError` translating Postgres error codes.

## Proposed Changes

### 1. `minidodo-infra/src/postgres/error.rs`
- `#[derive(Debug, Snafu)] pub enum Error` capturing `SqlxConnection`, `SqlxMigrations`, `QueryFailed`, `TransactionFailed`, `InvalidInput`.
- `impl From<Error> for MinidodoError` mapping:
  - `23505` (unique violation) -> `MinidodoError::Duplicate`
  - `23503` (foreign key) -> `MinidodoError::ConstraintViolation`
  - `23514` (check constraint) -> `MinidodoError::ConstraintViolation`
  - `40001` (serialization deadlock) -> `MinidodoError::DatabaseError` with `TRANSACTION_CONFLICT`
  - `SqlxError::RowNotFound` -> `MinidodoError::NotFound`
  - Connection/IO errors -> `MinidodoError::DatabaseConnection` with `CONNECTION_FAILED`

### 2. `minidodo-infra/src/postgres/connection.rs`
- `pub type ConnectionPool = sqlx::PgPool;`
- `pub type PgTransaction<'a> = sqlx::Transaction<'a, sqlx::Postgres>;`
- `establish_connection(database_url: &str, max_connections: u32) -> Result<ConnectionPool>`
- `begin_transaction(pool: &ConnectionPool) -> Result<PgTransaction<'_>>`
- `run_migrations(pool: &ConnectionPool) -> Result<()>` using `sqlx::migrate!("./src/postgres/migrations")`.

## Verification
- Unit test in `postgres/error.rs` testing Postgres code translations into `MinidodoError`.
