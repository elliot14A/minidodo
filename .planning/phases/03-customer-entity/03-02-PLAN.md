# Plan 03-02: Customer Domain Models and Database Actions

## Goal
Implement `Customer` domain model and pagination utilities in `minidodo-core`, along with granular database actions (`create`, `get_by_id`, `list_by_business`) in `minidodo-infra`.

## Proposed Changes

### 1. `minidodo-core`
- `models/customer.rs`:
  - `Customer` deriving `sqlx::FromRow`, `Serialize`, `Deserialize`, `ToSchema`.
  - `NewCustomer` struct with `name` and `email`.
- `utils/pagination.rs`:
  - `Pagination` and `PaginationResult<T>` with page/limit/offset calculations and Axum `FromRequestParts` query extractor support.

### 2. `minidodo-infra`
- `actions/customers/create.rs`: `create(pool, business_id, new_customer) -> Result<Customer>`.
- `actions/customers/get.rs`: `get_by_id(pool, business_id, customer_id) -> Result<Option<Customer>>` (tenant-scoped).
- `actions/customers/list.rs`: `list_by_business(pool, business_id, pagination) -> Result<PaginationResult<Customer>>` using `sqlx::QueryBuilder`.

## Verification
- `cargo check --workspace && cargo test --workspace`.
