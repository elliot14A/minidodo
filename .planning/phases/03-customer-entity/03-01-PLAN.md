# Plan 03-01: Customer Table Migration

## Goal
Create separate migration `0003_create_customers` with lowercase SQL, indexing on `(business_id, created_at desc)`, foreign key to `businesses(id)`, and non-nullable `name` and `email`.

## Proposed Changes

### 1. `minidodo-infra/src/postgres/migrations/0003_create_customers.up.sql`
- `create table if not exists customers (id uuid primary key default gen_random_uuid(), business_id uuid not null references businesses(id) on delete cascade, name varchar(255) not null, email varchar(255) not null, created_at timestamptz not null default current_timestamp);`
- Index: `create index if not exists idx_customers_business_id_created_at on customers(business_id, created_at desc);`

### 2. `minidodo-infra/src/postgres/migrations/0003_create_customers.down.sql`
- `drop table if exists customers;`

## Verification
- Run `cargo run -p minidodo-cli -- migrate` or docker migrate service.
- Verify `customers` table created in PostgreSQL with proper schema and indexes.
