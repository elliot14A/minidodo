# Plan 03-03: Customer 3-Tier API Endpoints & OpenAPI Documentation

## Goal
Implement customer HTTP endpoints with validation, `AuthContext` tenant scoping, JSON responses, and utoipa OpenAPI documentation:
- `POST /v1/customers`: Create customer.
- `GET /v1/customers/{id}`: Get customer by id.
- `GET /v1/customers`: List customers with pagination.

## Proposed Changes

### 1. `minidodo-server/src/http/routes/v1/customers/`
- `create.rs`: Handler with `ValidatedJson<CreateCustomerRequest>` returning `201 Created` with `JsonResponse<Customer>`.
- `get.rs`: Handler with `Path(customer_id)` returning `JsonResponse<Customer>` or `404 Not Found`.
- `list.rs`: Handler with `Pagination` returning `JsonResponse<PaginationResult<Customer>>`.
- `routes.rs`: Axum Router mounting `/` (POST, GET) and `/{id}` (GET).
- `mod.rs`: `CustomersApiDoc` OpenAPI definitions mounted into root `ApiDoc`.

## Verification
- `curl -X POST /v1/customers` with `Bearer dodo_test_key_12345` -> `201 Created`.
- `curl /v1/customers/{id}` -> `200 OK`.
- `curl /v1/customers` -> `200 OK` with paginated list.
