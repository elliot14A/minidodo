# Plan 04-03: Invoices 3-Tier API Endpoints (POST, GET, PATCH) & OpenAPI Documentation

## Goal
Implement invoice HTTP endpoints with input validation, `AuthContext` tenant scoping, guarded `PATCH` transitions with domain-specific 409 conflict errors, and utoipa OpenAPI documentation:
- `POST /v1/invoices`: Create invoice with line items (computes total, starts in `draft`).
- `GET /v1/invoices/{id}`: Get invoice details with line items.
- `GET /v1/invoices`: List invoices with pagination and filters (`state`, `customer_id`).
- `PATCH /v1/invoices/{id}`: Guarded state transition (`{"state": "open"}`, `{"state": "void"}`, `{"state": "uncollectible"}`).

## Proposed Changes

### 1. `minidodo-server/src/http/routes/v1/invoices/`
- Handlers:
  - `create.rs`: Validated JSON creating invoice + line items, returns `201 Created`.
  - `get.rs`: Returns `200 OK` with `InvoiceWithLineItems` or `404 Not Found`.
  - `list.rs`: Returns paginated invoices with optional query filters `state` and `customer_id`.
  - `update_state.rs`: Validated JSON `{"state": "..."}` executing status-conditional transition. Returns `200 OK`, `404 Not Found` (if missing/not owned), or `409 Conflict` (with `current_state` and `requested_state` if invalid transition).
- `routes.rs`: Axum Router mounting `POST /`, `GET /`, `GET /{id}`, `PATCH /{id}`.
- `mod.rs`: `InvoicesApiDoc` OpenAPI definitions mounted into root `ApiDoc`.

## Verification
- `curl -X POST /v1/invoices` -> `201 Created` with computed `total_cents` in `draft` state.
- `curl -X PATCH /v1/invoices/{id} -d '{"state":"open"}'` -> `200 OK` (transitioned to `open`).
- `curl -X PATCH /v1/invoices/{id} -d '{"state":"void"}'` -> `200 OK` (transitioned to `void`).
- `curl -X PATCH /v1/invoices/{id} -d '{"state":"open"}'` -> `409 Conflict` with JSON body:
  ```json
  {
    "message": "cannot mark invoice as 'open': invoice is in state 'void'",
    "code": "INVOICE_INVALID_STATE_TRANSITION",
    "current_state": "void",
    "requested_state": "open"
  }
  ```
- `curl /v1/invoices` -> `200 OK` with paginated list and filters.
