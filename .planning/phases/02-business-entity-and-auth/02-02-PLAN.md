# Plan 02-02: Domain Models & Database Actions for Business and API Key Lookup

## Goal
Define domain models (`Business`, `AuthContext`) in `minidodo-core` and implement pure async database action functions in `minidodo-infra` for business lookup and API key authentication.

## Proposed Changes

### 1. `minidodo-core`
- `src/models/business.rs`: `Business` struct deriving `Serialize`, `Deserialize`, `utoipa::ToSchema`.
- `src/models/auth.rs`: `AuthContext { pub business_id: Uuid }`.
- Export models via `models/mod.rs` and `lib.rs`.

### 2. `minidodo-infra`
- `src/postgres/actions/businesses/get.rs`:
  - `pub async fn get_business_by_id(pool: &ConnectionPool, business_id: Uuid) -> Result<Option<Business>>`
- `src/postgres/actions/apikeys/verify.rs`:
  - `pub async fn verify_api_key(pool: &ConnectionPool, token_hash: &[u8]) -> Result<Option<Uuid>>`
- Re-export modules under `postgres/actions/mod.rs`.

## Verification
- `cargo check --workspace` passes cleanly.
- Unit tests validating query parameter binding and action types.
