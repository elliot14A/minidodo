# Plan 02-03: Axum Auth Middleware, Business Get API Route & OpenAPI Docs

## Goal
Implement the Axum `AuthContext` extractor middleware validating Bearer API keys against Postgres, the `GET /v1/businesses/me` endpoint returning the authenticated business, and wire OpenAPI 3.1 schema definitions.

## Proposed Changes

### 1. `minidodo-server/src/http/middleware/auth.rs`
- Implements `FromRequestParts` for `AuthContext`.
- Extracts `Authorization: Bearer <token>`.
- Computes SHA-256 hash using `sha2::Sha256`.
- Calls `minidodo_infra::postgres::actions::apikeys::verify_api_key`.
- Returns `MinidodoError::Unauthorized` if missing or invalid.

### 2. `minidodo-server/src/http/routes/v1/businesses/`
- `get.rs`: `get_current_business(Extension(pool): Extension<ConnectionPool>, auth: AuthContext) -> Result<JsonResponse<Business>>`.
- `routes.rs`: Exposes `pub fn routes() -> Router` mounting `GET /me`.
- `mod.rs`: Defines `BusinessesApiDoc` OpenAPI sub-docs.
- `v1/mod.rs`: Nests `.nest("/businesses", businesses::routes())` and registers `BusinessesApiDoc` in root `ApiDoc`.

## Verification
- `cargo check --workspace` and `cargo test --workspace`.
- Test request `curl -i -H "Authorization: Bearer dodo_test_key_12345" http://localhost:3000/v1/businesses/me` returns `200 OK` with Acme Corp data.
- Test request with invalid or missing Bearer token returns `401 Unauthorized`.
