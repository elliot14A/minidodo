# Plan 06-01: Payment Attempts and Idempotency Keys Migrations

## Goal
Create PostgreSQL migrations for `payment_attempts` (`0006`) and `idempotency_keys` (`0007`) using lowercase SQL, integer minor units (`bigint` for cents), UUID v4 primary keys, and the indexes specified in DESIGN.md §1. Column `payload_hash` (not `request_fingerprint`).

## Proposed Changes

### 1. `minidodo-infra/src/postgres/migrations/0006_create_payment_attempts.up.sql`
- Enum `payment_status as enum ('pending', 'succeeded', 'failed')`.
- Table `payment_attempts`:
  - `id uuid primary key default gen_random_uuid()`
  - `invoice_id uuid not null references invoices(id) on delete cascade`
  - `business_id uuid not null references businesses(id) on delete cascade`
  - `idempotency_key text not null`
  - `payload_hash text not null`
  - `status payment_status not null default 'pending'`
  - `psp_ref uuid`
  - `psp_error_code text`
  - `created_at timestamptz not null default current_timestamp`
- Indexes:
  - `unique(business_id, idempotency_key)`
  - `idx_payment_attempts_invoice_id` on `payment_attempts(invoice_id)`

### 2. `minidodo-infra/src/postgres/migrations/0006_create_payment_attempts.down.sql`
- `drop table if exists payment_attempts cascade;`
- `drop type if exists payment_status;`

### 3. `minidodo-infra/src/postgres/migrations/0007_create_idempotency_keys.up.sql`
- Enum `recovery_point as enum ('charge_pending', 'finished')`.
- Table `idempotency_keys`:
  - `business_id uuid not null references businesses(id) on delete cascade`
  - `idempotency_key text not null`
  - `payload_hash text not null`
  - `recovery_point recovery_point not null default 'charge_pending'`
  - `locked_at timestamptz not null default current_timestamp`
  - `last_run_at timestamptz`
  - `response_code int`
  - `response_body jsonb`
  - `created_at timestamptz not null default current_timestamp`
  - `primary key (business_id, idempotency_key)`
- Index:
  - `idx_idempotency_keys_recovery` on `idempotency_keys(recovery_point, locked_at) where recovery_point <> 'finished'`

### 4. `minidodo-infra/src/postgres/migrations/0007_create_idempotency_keys.down.sql`
- `drop table if exists idempotency_keys cascade;`
- `drop type if exists recovery_point;`

## Verification
- Run migrations via `cargo run -p minidodo-cli -- migrate`.
- Verify tables, enums, the partial index, and foreign keys in Postgres.
- Fails when: migrate exits non-zero, or either table or index is absent in `\d+`.
